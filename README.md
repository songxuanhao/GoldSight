# GoldSight 金瞳

超短线国际黄金行情终端（Windows 便携版，免费）。

- 官网 / 下载页：https://goldsight.pages.dev
- 最新版本：https://github.com/songxuanhao/GoldSight/releases/latest
- 特性：成交量分布（VP）、订单流 CVD、短期走势卡、多窗格、模拟交易与历史回测、绘图与警报
- 数据：免费公开数据源（OKX/Gate 黄金代币逐笔、东方财富 COMEX 与新闻），无需注册、无需 API Key
- 模拟交易，不接真实账户，不构成投资建议

SHA256 在对应 Release 说明中给出。
