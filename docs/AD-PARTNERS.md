## 二、券商/期货开户类 CPA（按开户结算，单价高）

- 通常通过金融推广渠道平台（如部分「券商合作推广」平台），按开户/入金结算，几十~几百元/户。
- 注意：这类需要确认平台正规资质与结算方式，且不能承诺收益、不能荐股；先小批量试。
- 如果找到可个人接入的正规渠道，把推广链接发我，我做成「合作位」。

## 三、财经软件/数据服务直客（按月，价格最高）

- 同花顺、东方财富、Wind、文华财经、期货公司、投教机构的市场部/BD。
- 报价参考：垂直工具站 ¥15~30 / 千次曝光，或按月 ¥300~1500/位（看流量）。
- 需要给客户看数据：可接 Cloudflare Web Analytics（免费、隐私友好）提供曝光证明。

## 四、联盟 CPM（需要 ICP 备案域名）

- 百度联盟、腾讯优量汇、字节穿山甲：财经/金融类广告主较多，可自动按曝光/点击计费。
- 前提：域名完成 ICP 备案（约 7~20 天）。备案通过后可申请；我方广告位已支持贴 JS，接入零改动。

## 五、合规红线（必须遵守）

- 不接：博彩、贷款、虚拟币、荐股带单、配资、外汇黑平台、承诺收益类。
- 所有广告位必须保留「广告」标识（已强制显示），不得伪装成下载按钮或官方内容。
- 广告主资质与素材审核记录要留档；金融类广告尤其注意不得出现「稳赚」「保本」「荐股」等表述。
