# 国内广告/变现渠道说明（GoldSight 落地页）

## 结论先说

- **AdSense 不适合国内主站**：Google 广告脚本在国内经常加载失败，且 AdSense 审核更偏好自有域名 + 海外流量；当前页面已做失败回退（不白屏），但收入预期接近于 0。
- 国内主流广告联盟（百度联盟、腾讯优量汇、字节穿山甲、快手联盟）**都要求 ICP 备案域名**。`goldsight.pages.dev` 是 Cloudflare 子域，无法备案。
- 所以现在的最优组合是：
  1. **直客/赞助合作位**（已内置 house 模式，改 `site.json` 即可换内容）；
  2. **CPS/联盟链接**（京东联盟、淘宝客、多多进宝等，佣金模式，无需备案）；
  3. 等有预算和资质后，再「买域名 → 备案 → 接联盟」。

## 三种可落地方式

### A. 直接卖展示位（推荐先做）

- 页面顶部广告位 + 价格区下方广告位都可以直接换成合作方内容。
- 改 `F:\deepseek\工作区\GoldSight-web\assets\site.json` 的 `ads.house.items`（数组，支持多条轮换展示）。
- 定价参考：新站月流量 <1 万，展示位市场价大约 20~200 元/月；流量起来后按 CPM 谈（国内金融类 CPM 5~40 元）。
- 优点：立即可用、无审核、无备案；缺点：要自己找客户（黄金/交易/财经工具相关商家：券商开户、交易课程、EA/指标、行情软件）。

### B. CPS 联盟（无备案门槛）

- 京东联盟/淘宝客/多多进宝：把广告位换成带 `?union_id=...` 的推广链接，用户下单你拿佣金。
- 适合理财书、交易书籍、行情终端、打印机等周边；金融类商品佣金普遍 1%~10%。
- 注意：金融开户类 CPS 需要对应平台资质，别接「荐股/带单」类，容易违反广告法与平台规则。

### C. 国内广告联盟（需要备案域名）

- 百度联盟：需 ICP 备案 + 网站内容审核；金融类内容审核严格。
- 腾讯优量汇 / 穿山甲：主要是 App 流量，网页端接入有限。
- 流程：买域名（~50 元/年）→ 域名实名 → 买境内云服务器/轻量应用服务器（备案要求）→ ICP 备案（个人 1~3 周）→ 接入联盟。
- 只做落地页下载的话，备案与服务器成本 > 收益，除非你还有其他内容站。

## 页面里怎么切模式

`assets/site.json`：

```jsonc
"ads": {
  "enabled": true,
  "provider": "adsense",       // "adsense" 时填了 client+slot 才启用；留空自动用 house
  "adsense": { "client": "", "slots": { "top": "", "mid": "", "bottom": "" } },
  "house": {
    "enabled": true,
    "items": [
      { "label": "广告位", "title": "这里可以放你的产品", "text": "一句话说明", "href": "https://你的链接", "cta": "了解详情 →" }
    ]
  }
}
```

- 改完执行 `scripts\prepare-dist.ps1` → `scripts\deploy-pages.ps1`。
- 验证：打开页面控制台 `document.documentElement.dataset.ads` 应为 `house` 或 `adsense`。

## 现实预期

- 广告收入 = 流量 × 单价。站刚上线、日下载量 <50 时，广告月收入基本在 0~50 元区间。
- **软件本身 9.9 一次买断的转化率通常远高于广告**：下载 → 试用 7 天 → 付费，是很成熟的路径。
- 建议顺序：先把下载量做起来（发到黄金/交易社群、贴吧、B 站/抖音教程）→ 有稳定流量后再接赞助位或联盟。
